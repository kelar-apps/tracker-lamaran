Kebijakan Privasi

Kelar — Tracker Lamaran Kerja

Berlaku sejak 13 November 2026.

Kebijakan ini menjelaskan data apa yang dipakai oleh Kelar — Tracker Lamaran Kerja ("Kelar"), di mana data itu disimpan, dan bagaimana kamu bisa menghapusnya. Singkatnya: data lamaranmu disimpan di Google Drive milikmu sendiri, bukan di server kami.

1. Data yang dipakai

Dari akun Google-mu

  • Nama dan alamat email, untuk menyapamu di aplikasi dan memeriksa apakah kamu sudah membeli akses.
  • Akses ke file buatan Kelar di Google Drive (izin drive.file). Kelar hanya bisa membuat dan membuka file yang dibuatnya sendiri, yaitu spreadsheet "Kelar — Tracker Lamaran". Kelar tidak bisa melihat file lain di Drive-mu.

Yang kamu ketik sendiri

Data lamaran (perusahaan, posisi, status, jadwal, catatan, kontak HR, dan lainnya) serta pengaturan seperti target mingguan. Semuanya ditulis ke spreadsheet di Drive-mu.

2. Di mana data disimpan

  • Google Drive milikmu: spreadsheet berisi semua data lamaranmu.
  • Browser di perangkatmu (localStorage): salinan data supaya aplikasi cepat dibuka dan bisa dibaca saat offline, serta nama dan email untuk tampilan. Token akses Google tidak pernah disimpan; token hanya ada di memori selama aplikasi terbuka.
  • Server lisensi Kelar (Google Apps Script milik penjual): saat kamu masuk, aplikasi mengirim token akses sementara ke server ini. Server memeriksa token itu ke Google untuk mendapatkan email-mu yang terverifikasi, lalu mencocokkannya dengan daftar pembeli. Token tidak disimpan dan tidak dicatat. Daftar pembeli berisi email, produk, tanggal, dan nomor referensi pembelian.

Kelar tidak punya database sendiri untuk data lamaranmu, dan kami tidak bisa membuka spreadsheet di Drive-mu.

3. Yang tidak kami lakukan

  • Tidak menjual atau membagikan datamu ke pihak lain.
  • Tidak memakai iklan, pelacak, atau analytics.
  • Tidak memakai datamu untuk melatih AI.

4. Penggunaan data Google

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh Kelar mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use. Data dari Google hanya dipakai untuk menjalankan fitur Kelar yang kamu lihat di aplikasi.

5. Menghapus data dan mencabut akses

  • Keluar di menu Pengaturan menghapus semua data Kelar dari browser di perangkat itu dan mencabut token akses.
  • Hapus spreadsheet "Kelar — Tracker Lamaran" dari Google Drive-mu untuk menghapus data lamaranmu sepenuhnya.
  • Cabut izin Kelar kapan saja di myaccount.google.com/permissions.
  • Untuk menghapus email-mu dari daftar pembeli, hubungi kami lewat email di bawah.

6. Keamanan

Semua koneksi memakai HTTPS. Teks yang kamu ketik ditulis ke spreadsheet sebagai teks biasa (tidak dijalankan sebagai rumus). Aplikasi hanya membuka link lowongan yang diawali http:// atau https://.

7. Perubahan kebijakan

Kalau kebijakan ini berubah, versi terbaru akan dipasang di halaman ini dengan tanggal berlaku yang baru.

Summary in English

Kelar stores your job-application data in a spreadsheet in your own Google Drive, using the drive.file scope (access only to files Kelar creates). Your name and email are used to greet you and to check your purchase: a short-lived access token is sent to Kelar's license server (Google Apps Script), which verifies it with Google and is never stored or logged. A copy of your data is cached in your browser for offline use; access tokens are kept in memory only. We do not sell or share data, and use no ads or analytics. Kelar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Sign out to clear local data, delete the spreadsheet from Drive, or revoke access at myaccount.google.com/permissions. Contact: {{CONTACT_EMAIL}}.
